# بستهٔ فارسی‌سازی DeepTutor (fa-pack)

فارسی‌سازی کامل DeepTutor: رابط کاربری، خروجی مدل، راست‌به‌چپ، فونت وزیرمتن، تقویم شمسی (جلالی) با اعداد فارسی، و پیام‌های خطا — با یک دستور، قابل تکرار بعد از هر آپدیت.

## پیش‌نیازها
- DeepTutor نصب‌شده در یک venv (نصب pip رسمی یا فورک خودتان).
- Python 3.10+ (هر Python که `json`/`glob` استاندارد را داشته باشد کافی است).
- **Node.js (اختیاری ولی توصیه‌شده)**: اگر نصب باشد، پک بعد از هر تغییر سینتکس فایل‌های JS را با `node --check` تأیید می‌کند و اگر تغییری سینتکس را خراب کند خودش آن را از بکاپ برمی‌گرداند. بدون Node هم پک کار می‌کند، فقط این تور ایمنی خاموش است.

## مسیر نصب را معرفی کن
پک باید بداند DeepTutor کجاست. متغیر `DEEPTUTOR_HOME` را روی پوشه‌ای بگذار که `.venv` نصب‌شده را دارد:

```powershell
# ویندوز (PowerShell) — نمونه:
$env:DEEPTUTOR_HOME = "C:\deeptutor-home"
# لینوکس/مک:
export DEEPTUTOR_HOME="$HOME/deeptutor-home"
```

اگر DeepTutor را با `pip install deeptutor` داخل یک venv نصب کرده‌ای، همان پوشهٔ والد `.venv` را بده. ساختار site-packages ویندوزی و لینوکسی هر دو پشتیبانی می‌شود.

## نصب (۳ دستور)
```bash
cd fa-pack
python reapply_fa.py        # اعمال کامل + بکاپ خودکار + گزارش
python verify_fa.py         # تأیید نهایی (۲۶ چک) — باید OK: 26 باشد
deeptutor stop && deeptutor start
```
سپس در مرورگر **Ctrl+Shift+R** (یک بار، برای دور شدن از چانک‌های کهنهٔ کش).

## تفسیر خروجی reapply_fa.py
- `OK` = الان اعمال شد. `SKIP` = از قبل اعمال بود (طبیعی و درست). `FAIL` = لنگر پیدا نشد؛ یعنی نسخهٔ جدید DeepTutor ساختار آن بخش را عوض کرده.
- چهار گامِ «کاتالوگ» هر اجرا `OK` می‌دهند چون منبع ترجمه همیشه از نو کپی می‌شود — طبیعی است.
- جمع آخر: `FAIL: 0` یعنی سالم. هر `FAIL` را به‌همراه خروجی `verify_fa.py` برای نگهدارندهٔ بسته بفرست.
- جستجو بر اساس **محتوا** است نه نام فایل، پس تغییر نام چانک‌ها در بیلدهای جدید مشکلی ایجاد نمی‌کند.

## تأیید (verify_fa.py)
```bash
python verify_fa.py              # فایل‌ها + تست زندهٔ سرور (اگر روشن باشد)
python verify_fa.py --no-live    # فقط فایل‌ها
python verify_fa.py --url http://127.0.0.1:PORT
```
هر چک یا `OK` است یا `FAIL` با توضیح؛ کد خروج ۰ یعنی همه‌چیز آماده است. (شل HTML سمت سرور انگلیسی است — فارسی‌سازی سمت کلاینت اعمال می‌شود؛ تست نهایی ظاهری، یک Ctrl+Shift+R در مرورگر است.)

## عیب‌یابی
| مشکل | علت و کار |
| --- | --- |
| گامی `FAIL` داد | آپدیت DeepTutor ساختار را عوض کرده؛ خروجی reapply + verify را برای نگهدارنده بفرست |
| بعد از اجرا هنوز انگلیسی/فونت قدیمی | کش مرورگر — Ctrl+Shift+R؛ اگر نشد `deeptutor stop/start` و دوباره |
| تاریخ داخل فیلد تاریخ میلادی ماند | محدودیت ذاتی مرورگر است: متن فیلد `input[type=date]` بومی را خود مرورگر می‌کشد و value آن استاندارداً ISO میلادی است؛ پاپ‌آپ انتخاب تاریخ و تبدیل‌ها جلالی‌اند. راه‌حل کامل فقط با کامپوننت تاریخ سفارشی در سورس (PR) |
| بعد از آپدیت DeepTutor بعضی متن‌ها انگلیسی شد | رشته‌های تازه تا ترجمهٔ بعدی انگلیسی می‌مانند (fallback خودکار)؛ reapply را دوباره اجرا کن |
| `FAIL: deeptutor در ... پیدا نشد` | `DEEPTUTOR_HOME` اشتباه است — پوشه‌ای بده که `.venv` دارد |
| چیزی خراب شد و می‌خواهی برگردی | `python restore_fa.py` (بخش بعد) |

## بازگشت تغییرات
هر اجرای reapply قبل از بازنویسی هر فایل، نسخهٔ اصلی را زیر `fa-pack/backup/<زمان>/` کپی می‌کند:
```bash
python restore_fa.py --list      # فهرست بکاپ‌ها
python restore_fa.py             # بازگرداندن از آخرین بکاپ
python restore_fa.py 20261105-012345
```
بعد از بازگرداندن: `deeptutor stop/start` و Ctrl+Shift+R. هر بکاپ مستقل است؛ پوشهٔ `backup` را هر وقت خواستی می‌توانی خالی کنی.

## بعد از هر آپدیت DeepTutor
همان ۳ دستور نصب را دوباره اجرا کن (پک idempotent است — اجرای تکراری بی‌ضرر است).

## محدودیت‌های شناخته‌شده
- فیلد تاریخ بومی (بالا — توضیح در جدول عیب‌یابی).
- متن‌های صفحهٔ خطای مسیرها در سورس رسمی هاردکد انگلیسی‌اند؛ پک آن‌ها را در بیلد فارسی می‌کند، ولی راه درست، کلیددارکردن‌شان در سورس است.
- اگر DeepTutor را از سورس خودِ فورک بیلد کنی، بخش‌هایی که به سورس منتقل شده‌اند (تقویم جلالی، `FaDateInput`، …) دیگر نیازی به پک ندارند و گام‌هایشان `SKIP` می‌شود.

## ساختار بسته
- `reapply_fa.py` — اعمال کامل (۶۸ گام: بک‌اند + فرانت + فونت + RTL + تقویم) با بکاپ خودکار و گیت سینتکس
- `verify_fa.py` — تأیید نهایی ۲۶ چکی با تست زنده
- `restore_fa.py` — بازگشت از بکاپ
- `locales/fa/app.json` + `common.json` — منبع اصلی ترجمه (۶٬۴۳۵ کلید)
- `snippets.json` — بلوک‌های بک‌اند (پیام‌های i18n، بنر، خلاصه کتاب، اکسپورت، داور کوئیز، نام‌های مستعار)
- `fonts/Vazirmatn-var.woff2` — فونت وزیرمتن متغیر (۱۰۰–۹۰۰)
- `scripts/jalali_enhancer.js` — تقویم شمسی (inline در layout تزریق می‌شود)
- `scripts/` — اسکریپت‌های مرحله‌به‌مرحله (مرجع/اشکال‌زدایی)
- `backup/` — بکاپ‌های خودکار (بعد از اولین اجرا ساخته می‌شود)

## یادداشت نگهدارنده (بیلد از سورس)
از فاز ۵ (کامیت‌های `bf1b290` و `3c8a4b1`) بخش زیادی از کار در سورس فورک است: تقویم جلالی کامل (مدل `dates.ts`، `MonthView`، `MiniMonth`، `CalendarPage`)، `FaDateInput` با `withTime`، `InlineMarkdown` با `dir="auto"` بی‌قیدوشرط، خواص منطقی tray popover و فلش‌های `scaleX(-1)` تقویم. اگر بیلد سورس را در `deeptutor_web` نصب کردی، گام‌های مربوطه `SKIP` می‌شوند (لنگرشان نیست) — `SKIP` را با `FAIL` اشتباه نگیر.

دیپلوی بیلد تازه از سورس (به‌جای انتظار برای انتشار):
```bash
# در ریپو (%TEMP%/DeepTutor-pr)
cd web && npm run build
cd .. && .venv/Scripts/python.exe scripts/prepare_web_package.py --skip-build
# جایگزینی کامل قالب (glob * دات‌فایل .next را پاک نمی‌کند → با find)
DST="F:/deeptutor-home/.venv/Lib/site-packages/deeptutor_web"
find "$DST" -mindepth 1 -maxdepth 1 ! -name "__init__.py" -exec rm -rf {} +
cp -rf deeptutor_web/. "$DST"/
# سپس: deeptutor stop/start — لانچر خودش runtime cache را از قالب می‌سازد (mtime)
```
پس از ری‌استارت، در بریج/مرورگر زبان را از `/api/settings/ui` روی `fa` بگذار و Ctrl+Shift+R.
